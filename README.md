## 프로젝트 개요

본 프로젝트는 Wolfenstein 3D 게임을 기반으로 Ray-Casting 기법을 구현하는 것을 목표로 합니다. [cite: 1, 2] 미니LibX 라이브러리를 사용하여 2D 맵을 3D 시점으로 렌더링하고, 사용자와의 상호작용을 처리합니다.

## 구현 내용

### 필수 요구사항

* 미니LibX 라이브러리 사용
* 창 관리 (최소화, 다른 창으로 전환 등)
* 벽 텍스처 렌더링 (방향에 따라 다른 텍스처 적용)
* 천장 및 바닥 색상 설정
* 키보드 입력 처리
    * 좌우 화살표 키: 좌우 시점 변경
    * W, A, S, D 키: 맵 이동
    * ESC 키: 프로그램 종료
* 창 닫기 버튼 클릭 시 프로그램 종료
* `.cub` 확장자 맵 파일 파싱
    * 맵은 '0' (빈 공간), '1' (벽), 'N', 'S', 'E', 'W' (플레이어 시작 위치 및 방향) 문자로 구성
    * 맵은 벽으로 둘러싸여 있어야 함
    * 맵 외 요소들은 빈 줄이나 공백으로 분리 가능
    * 맵은 파일에 작성된 그대로 파싱
* 맵 파일 예시
* 맵 파일 파싱 에러 처리 ("Error\\n"과 함께 에러 메시지 출력 후 종료)

### 보너스 요구사항

저는 아래의 보너스 요구사항들을 구현했습니다.

* 벽 충돌 처리
* 미니맵 시스템
* 문 개폐 기능
* 애니메이션 스프라이트
* 마우스로 시점 회전

## 사용 방법

1.  저장소를 클론합니다.
2.  Makefile을 사용하여 프로그램을 컴파일합니다.
    * `make` : 필수 과제 컴파일
    * `make bonus` : 보너스 과제 포함 컴파일
3.  `.cub` 맵 파일을 인자로 실행합니다.
    * `./cub3D map.cub`
